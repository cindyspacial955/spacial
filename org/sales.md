# 営業部 ― 業務定義

## ミッション

コワーキングスペース・シェアオフィス施設への機器設置契約を獲得し、
Spacial の設置拠点数を拡大する。

---

## 主な責任領域

### 1. 見込み顧客の開拓（リストアップ）
- ターゲットエリアのコワーキング施設を調査・リスト化（`sales/prospects.csv`）
- 施設規模・トイレ数・担当者情報の収集
- 優先度スコアリング（席数・利用者数・立地）

### 2. 初回アプローチ
- 初回メール送付（`sales/templates/initial_email.md`）
- 電話フォローアップ（メール送付後3〜5営業日）
- SNS（LinkedIn/X）経由でのアプローチ

### 3. 商談・クロージング
- 施設ヒアリング（トイレ数・利用者属性・現在の課題）
- 無料トライアル提案・条件調整
- 契約書の取り交わし（最終承認はCEO）

### 4. 導入後フォロー
- 設置後1週間・1ヶ月の定期連絡
- 効果データの共有・本契約移行の促進
- 既存顧客からの紹介獲得

## 担当エリア・優先順位

### 【最優先】埼玉県（大宮・さいたま新都心・与野）

| 施設名（候補） | エリア | 備考 |
|-------------|--------|------|
| INNOBASE（イノベース） | さいたま新都心 | NTTアーバンソリューションズ運営・大規模 |
| BIZ SMART さいたま新都心 | さいたま新都心 | 三菱地所系チェーン |
| コワーキングスペース7F | 大宮 | 地域密着型・認知度高 |
| いいオフィス 大宮 | 大宮 | 全国チェーン展開 |
| fabbit 大宮 | 大宮 | 全国チェーン展開 |
| basis point 大宮 | 大宮 | 全国チェーン展開 |
| さいたま市産業創造財団施設 | 大宮周辺 | 行政系・信頼性高 |
| 与野周辺シェアオフィス各種 | 与野 | 個別調査が必要 |

### 【並行対応】東京都内

| エリア | アプローチ方針 |
|--------|--------------|
| 新宿・渋谷 | 大手チェーン（WeWork・SPACES等）への法人営業 |
| 池袋・上野 | 埼玉からの通勤利用者が多い駅周辺を優先 |
| 秋葉原・神田 | IT系利用者多いエリア・広告主とのマッチング良好 |
