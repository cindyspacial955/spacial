# CEO（代表取締役）― 業務定義

## ミッション

Spacial の事業ビジョンを体現し、会社全体の意思決定・対外代表・戦略策定を担う。

---

## 主な責任領域

### 1. 経営戦略
- 事業フェーズごとの優先順位設定（現在：コワーキング向け機器設置の初期営業）
- 収益モデルの設計・見直し（広告収益シェア / 月額課金 等）
- 中期事業計画（3〜12ヶ月）の策定

### 2. 対外折衝・パートナーシップ
- 大口施設との経営層レベルの商談・最終クロージング
- 広告主・メディアパートナーとの提携交渉
- 投資家・金融機関への説明対応（財務部と連携）

### 3. 採用・組織構築
- 初期メンバー採用の最終判断
- 組織カルチャー・バリューの設定

### 4. プレスリリース・広報
- メディア対応・インタビュー
- SNS公式アカウントでの代表メッセージ発信

---

## 週次ルーティン

| 曜日 | 業務 |
|------|------|
| 月 | 週次全体ミーティング（各部門KPI確認）/ 秘書と週間スケジュール確認 |
| 火〜木 | 重要商談・パートナー会議 |
| 金 | 週次振り返り・翌週アクションプランニング |

## 意思決定権限

| 項目 | CEOの判断が必要 |
|------|---------------|
| 契約締結 | 月額10万円以上または3ヶ月超の契約 |
| 支出承認 | 1件10万円以上 |
| 採用決定 | 全メンバー |
| 事業方針変更 | 常時 |
