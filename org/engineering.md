# エンジニアリング部 ― 業務定義

## ミッション

トイレサイネージ機器の設置・保守・コンテンツ配信システムを管理し、
Spacial サービスの技術的な品質と安定稼働を担保する。

---

## 主な責任領域

### 1. 機器設置・撤去

- 設置前の現地調査（トイレ個室サイズ・電源位置・Wi-Fi状況確認）
- 機器の設置工事・設定（サイネージデバイス・固定具・電源工事）
- トライアル終了時または解約時の機器撤去
- 設置記録の作成（写真・設置仕様書）

**設置チェックリスト**
```
□ 電源コンセントの有無・位置確認
□ Wi-Fi電波強度確認（-70dBm以上推奨）
□ 機器固定方法の選定（粘着・ネジ止め・専用金具）
□ 機器の電源投入・ネットワーク接続確認
□ コンテンツ配信テスト（初期コンテンツ表示確認）
□ 施設担当者への操作説明
□ 設置完了報告書の提出
```

### 2. コンテンツ配信システム管理

- クラウドCMS（コンテンツ管理システム）の運用
- 施設ごとのコンテンツスケジューリング
- 広告コンテンツの登録・配信確認
- 施設からのコンテンツ更新依頼への対応（SLA：依頼後24時間以内反映）

### 3. 機器保守・障害対応

- リモート監視（機器の死活監視・コンテンツ表示確認）
- 障害発生時の初動対応（リモートリスタート → 現地対応）
- SLA: 障害報告後4時間以内に初動、翌営業日中に解消
- 定期メンテナンス（月1回の動作確認・清掃案内）

### 4. システム開発（将来）

- 施設管理ポータル（施設担当者がコンテンツを自己管理）
- 広告主向けダッシュボード（表示回数・エンゲージメント可視化）
- 効果測定機能（QRコード読み取り数・時間帯別表示回数）
