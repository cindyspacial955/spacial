# コワーキングスペース 見込み顧客リスト 作成ガイド

## ターゲット基準

| 項目 | 優先度高 | 優先度中 | 優先度低 |
|------|---------|---------|---------|
| 席数 | 50席以上 | 20〜49席 | 20席未満 |
| 運営形態 | チェーン展開 | 独立複数拠点 | 単店舗 |
| トイレ数 | 4室以上 | 2〜3室 | 1室 |
| 月会員比率 | 60%以上 | 30〜59% | 30%未満 |

## リスト収集方法

1. **コワーキングデータベース** https://coworking-db.com/ で施設一覧を取得
2. **Google Maps** で「コワーキングスペース 渋谷」等で検索し、店舗情報を収集
3. **公式サイト** で担当者・問い合わせ先を特定
4. **LinkedIn** で施設担当者・マネージャーを検索

## prospects.csv への記入方法

`sales/prospects.csv` を編集してリストを管理する。

| カラム | 内容 |
|-------|------|
| id | 連番 |
| 施設名 | 正式名称 |
| 住所 | 都道府県・市区町村まで |
| 担当者名 | 判明した場合 |
| 担当者メール | 判明した場合 |
| 担当者電話 | 判明した場合 |
| 席数規模 | 概数（例: 80席） |
| 月額想定単価 | 見積もり（例: 50,000円） |
| ステータス | 未接触 / メール送付済み / アポ獲得 / 商談中 / 提案済み / 成約 / 見送り |
| 初回接触日 | YYYY-MM-DD |
| 次回アクション日 | YYYY-MM-DD |
| 次回アクション内容 | 具体的なアクション |
| 備考 | 自由記述 |
